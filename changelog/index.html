Changelog

Release notes for every version.

6.0.16 Oct 19, 2026
  • Composer (desktop): the enhanced composer adds a formatting bar for bold, italic, underline, strikethrough, code, spoilers and colors. It is on for Modern and off for Classic by default, with a switch for each in Settings > Appearance > Transcript Layout.
  • Composer (desktop): Live formatting (experimental) shows bold, colors and code as they will look while you type. Formatting codes stay hidden until your cursor reaches them.
  • Shortcuts (desktop): Ctrl+B, I and U and Ctrl+Shift+X apply bold, italic, underline and strikethrough (Cmd on macOS). A second press removes the style. Nicklist collapse/expand was moved to Ctrl+N instead of Ctrl+U.
  • Composer (desktop): Up and Down move between wrapped lines and only recall history from an empty composer. The typing indicator now rests below the composer and uses the proper nick color to identify users.
  • Nick list (desktop): in Modern, the topic card has a toggle showing the first few members and the member count. Click it to open or close the nick list.
  • Treebar (desktop): a small tab on the treebar's edge collapses and expands it, in place of the corner button.
  • Topic bar (desktop): the topic bar now matches the active network card's outline. A new Topic Bar Highlight slider sits beside Active Network Highlight.
  • Link previews (desktop): on Windows, YouTube links play in place, and nothing contacts YouTube until you press play. Pages with no preview image show the site's icon instead.
  • Modern layout (desktop): Messages fill more horizontal area of the transcript, and summaries line up with message text. Improved identicon visuals by solidifying them to preserve fidelity on light themes.

  • Go updates to address security and functionality fixes.

6.0.13 Oct 13, 2026
  • Themes (desktop): Cyberpunk is a new built-in theme in electric yellow and cyan, with six neon nick colors.
  • Theme editor (desktop): the Atmosphere section adds a circuit pattern behind the channel tree, with its own color and strength. Circuits and stars can each extend into the nicklist. Cyberpunk and Hackerman use circuits by default.
  • Theme editor (desktop): Reset now returns a color to where it was when you opened the editor, instead of discarding earlier changes.
  • Theme refresh (desktop): Monokai becomes Monokai Pro, and Gruvbox moves to Gruvbox Material with an orange accent. Nord, Dracula and Catppuccin sit on one flat background as their originals do, and Seraph is sharper, with easier-to-read nicks and event lines.
  • Treebar (desktop): a new Active Network Highlight setting in Settings > Appearance > Window sets how strongly the active network's card is outlined. Card outlines are easier to see on light themes.
  • Windows (desktop): Dock All on the toolbar and in the Window menu sends every open window to the treebar at once.
6.0.12 Oct 11, 2026

  • Channel Info (desktop): opens from a new info button in the topic bar. Ban and invite exceptions can be viewed and edited beside bans, and more channel modes are listed where the server supports them.
  • Connection Health (desktop): Expanded horizontal width on information cards. This should make it less treacherous to read. 🙂
  • Themes (desktop): Aura is the default for new installs. Your saved theme stays as it is. Miami Nights' sunset glow now follows the Atmosphere slider like every other glow.

  • Member list (desktop): on InspIRCd servers, a channel's member list no longer goes blank for an extended period right after you join.

6.0.3 Oct 1, 2026
  • Certificate login (desktop): direct networks can sign in with a client certificate (SASL EXTERNAL). SeraphIRC makes one for each network and registers it with NickServ for you on your next login.
  • Close to tray (Windows & macOS): closing the window can hide SeraphIRC to the system tray so you stay connected. The first close asks, and you can change it later in Settings > Application > Close Behavior.
  • One copy per profile (Windows & macOS): opening SeraphIRC while it is already running brings up the running window instead of starting a second client on the same nicks.
  • Live transcripts (desktop): new messages show up while you type and during fast floods, instead of waiting for a pause. Channels restored at startup show their history without a click.
  • Missed history (mobile & desktop): after a reconnect, a busy channel fills in much more of what you missed, not just the most recent page.
  • App icon (Linux): deb and rpm installs show the SeraphIRC icon in the dock and taskbar again. If you pinned the app, pin it once more after updating.

6.0.1 Sep 28, 2026

6.0.0 Sep 28, 2026
  • Scripting (desktop): SeraphIRC now runs scripts written in the mIRC scripting language, with aliases, events, timers, popups, custom windows, and file and socket commands. Most classic scripts load with /load and run unchanged.
  • Scripts Editor (desktop): a new editor with Aliases, Popups, Remote, Users and Variables tabs, plus an Errors tab for anything that went wrong this session. Any script file can be switched off or limited to certain networks.
  • Script safety (desktop): a new script asks before it loads, and again before it connects to a new host. Scripts are paced so they never flood you off a server, and if one crashes the app on startup, the next start opens with scripts off.
  • Menus (desktop): scripts can add items to the right-click menus and a Commands menu on the menu bar. The Edit menu gains Undo and Redo.
  • Aliases (desktop): your existing aliases move into the Scripts Editor on first start and work as before. The built-in /close is now /closebuffer, so scripts can define their own.
  • Pasting commands (desktop): a pasted block of commands keeps its lines, and Enter runs them in order. Nothing runs until you press Enter.
  • Text art (desktop): colored blocks use the true IRC palette, the MOTD keeps the server’s colors, and a banner keeps every line after a restart.
  • Spacing (desktop): messages, the user list and the treebar can go tighter than before, with Comfortable and Roomy presets. Your current spacing does not change.
  • More (desktop): EsperNet and HybridIRC join the default networks, the classic layout fits a full 16-character nick, and a reset offers to back up your scripts first.
