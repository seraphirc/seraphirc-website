What's new in SeraphIRC.

Detachable windows are here

Oct 30, 2026, version 6.0.23

Version 6.0.23 lets you pull a conversation out of the main window. Any channel, query or DCC chat can now live in a window of its own.

Detach. Click the Detach window button on a window's titlebar, or right-click a channel or query and choose Detach Window. It opens as a separate window that you can drag anywhere on screen or onto a different monitor. Keep a busy channel on your second display while you chat in the main app, or float a private conversation beside your work.

Reattach. When you are done, click Reattach window on the detached window's titlebar, choose Reattach Window from the right-click menu, or just close it. The conversation docks back into the main window.

Detached windows follow your theme and stay in sync with the main app, so settings you change in one apply to all of them.

Enhanced composer

Oct 19, 2026, version 6.0.16

Version 6.0.16 brings the enhanced composer. Like the message box in other modern workspace apps, it puts formatting tools right above where you type.

Formatting bar. Bold, italic, underline, strikethrough, code, spoilers and colors are one click away. The color picker sets text and background colors from the full extended palette. Ctrl+B, I and U work too (Cmd on macOS), and Ctrl+Shift+X adds strikethrough.

Live formatting. Enable Live Formatting (experimental) in Settings > Appearance > Transcript Layout and your draft shows bold, colors and code as they will look once sent.

The enhanced composer is on by default in the Modern layout. To preserve the experience, classic mode remains defaulted to the standard composer window. If you'd like to switch it on, it can be enabled within the Settings > Appearance > Transcript Layout section.

New built-in theme

Oct 13, 2026, version 6.0.13

Version 6.0.13 brings Cyberpunk, a new built-in theme. It pairs electric yellow with cyan, adds red for alerts, and gives nicks six neon colors that stay easy to read.

Circuits. A faint circuit-board pattern can now sit behind the channel tree under the stars and the glow. Cyberpunk draws it in cyan and Hackerman in green. Any theme can turn it on with its own color and strength.

Atmosphere in the nicklist. Circuits and stars can both extend into the nicklist. Each one is optional and has its own switch.

More options to make the UI feel like your own. You will find them in the theme editor's Atmosphere section.

Treebar Upgrades

Oct 11, 2026, version 6.0.12

Version 6.0.12 gives the treebar a new look we call Constellation.

Networks as cards. Each network sits in its own card, with its status light, a Soju or Direct chip, and an unread total. Under the name, the card shows which server answered and how fast. The network you are working in carries a faint glow, and the latency graph at the bottom is a card to match.

Easier to scan. Section captions show their count, the selected window is a lit, outlined capsule, and rows with mentions or private messages waiting stand out with a badge. In the Modern layout, private messages lead with the person's avatar.

Clearer on light themes. Themes with a light treebar, Sage and Sakura among them, now use darker small labels that are much easier to read.

Wail Wail Wails

Sep 30, 2026, version 6.0.2

The desktop app runs on Wails, the framework that puts SeraphIRC in a native window on Windows, macOS and Linux. Version 6.0.2 moves it from Wails 2 to Wails 3. Your settings and scripts carry over.

Sharper on Linux. On Hyprland and other displays scaled fractionally, the window is now crisp instead of soft and blurry.

On the living version. Wails 3 is where the Wails team puts its new work, so SeraphIRC keeps up as Windows, macOS and Linux change.

What changed. macOS now needs version 12 (Monterey) or later. On Linux, SeraphIRC now uses GTK 4 and WebKitGTK 6.0, which current distributions include.

Scripting phase 1 arrives

Sep 28, 2026, version 6.0.0

SeraphIRC now runs scripts written in the mIRC scripting language. Aliases, events, timers, popups, custom @windows, hash tables, and file and socket commands all work, and most classic scripts load with /load and run as they are.

Everything lives in the new Scripts Editor, opened with Alt+R. Your existing aliases have already moved in, and each script file can be switched off or kept to certain networks. A script asks before it first loads and before it connects to a new host, and what it sends is paced so it never floods you off a server.

Phase 1 is mIRC script support. Phase 2 is Lua/Python. Dialogs and picture windows are planned for a later 6.x release. If a script you rely on misbehaves, tell us and we will work with you on a fix.

So much room for activities!

Sep 15, 2026, version 5.1.25

The feedback we hear most is that the UI takes up too much of the window. Two new options in Settings > Appearance hand that space back.

Reactions

Aug 28, 2026, version 5.1.14

React to any message with an emoji, on desktop and mobile alike. Pick React from a message's menu or type /react, choose from the full emoji picker, and the reaction appears as a small chip on the message for everyone whose client supports it.

Native FiSH Implementation

Aug 21, 2026, version 5.1.7

SeraphIRC now includes a native FiSH implementation, the Blowfish encryption used by HexChat, Konversation, Quassel and mIRC for years. Set a shared key for a channel or a person and everything you send there goes out encrypted. The people you talk to on those other clients can read you, and you can read them.

A lock marks what was protected on the conversation in the tree and title bar as well as on each message that traveled encrypted. This way, you never have to guess whether a line went cleartext. If you'd rather not type commands, a Blowfish Settings panel on desktop and mobile holds the key for each conversation, and the desktop can negotiate one with the other side for you.

Mobile caveat: mention notifications cannot arrive for encrypted channel messages, because your bouncer cannot read them to spot your name. Direct messages still notify.

Ignore once, ignored everywhere

Aug 15, 2026, version 5.1.2

Ignore someone on the desktop and your phone never got the memo, so the same person kept turning up in your pocket. On a soju bouncer that is over. Ignore a nick on one device and the other has them ignored too, and unignoring travels back the same way. It rides soju's soju.im/blocked key, so a phone that was asleep catches up on reconnect, and soju stops pushing notifications from anyone on the list. Syncing needs a Soju version that offers soju.im/blocked. On an older bouncer, ignores keep working per device.

Entries are IRC masks now, so troll* survives the inevitable nick change, and an ignore covers notices, invites and the join and quit noise rather than only messages. Every row says whether it syncs or lives on this device alone.

Settings > Ignore List

Seraph your way

Aug 4, 2026, version 5.0.28

SeraphIRC ships with 21 themes, and until today that was the whole menu. Now any of them is a starting point. Clone one, give it a name, and recolor it from a floating editor that paints every change onto the running app as you make it. Every color is named for the thing it paints on screen, so you are choosing "Timestamps" or "Selected channel background", not deciphering a stylesheet. Pick from the palette the theme already uses, dial in something new on a full color wheel, or build a gradient. Your client, your colors.

Made something worth showing off? Export it. A theme travels as a small file that carries its name and colors and nothing else, never your networks or credentials, so you can hand it to a friend or drop it in a channel. Imported themes are checked before a single color lands. And the originals are never touched, so there is always a way back.

Settings > Preferences > Appearance

Additional IRCv3 Capabilities

Aug 2, 2026, version 5.0.24

Two IRCv3 extensions land together. Multiline lets a long message, or one with line breaks in it, travel as a single message instead of being chopped into a run of separate lines. Replies point a message at the one it answers, so the client draws that parent above it with a jump back to where it sits in the conversation.

Both fail gracefully, because most of IRC has not caught up yet. Multiline is used only where the network offers it and your message actually needs it. A reply that cannot be tagged opens with nick: instead, the way IRC has addressed people for thirty years, so it reads correctly on every client ever written. Where the tag does travel, SeraphIRC hides the now-redundant prefix and draws the preview in its place.

Right-click a message > Reply

Check yourself, before you... yeah.

Jul 30, 2026, version 5.0.18

IRC has no undo. Send Guard reads a message on its way to the wire and holds the ones that look like an accident: a password typed into a channel instead of a services window, a private line addressed to someone who isn't in the room, a forty-line paste into a busy channel.

A held message waits in a banner above the composer that names the destination and says which rule stopped it. Enter is deliberately not the confirm key, because the reflex that just sent the secret is a second tap on Enter. Send anyway is Ctrl+Enter, or Cmd+Enter on macOS, or a click. Escape drops the line, and editing it runs the check again.

Settings > Send Guard

Straight from your machine to theirs

Jul 28, 2026, version 5.0.15

Peer-to-peer file transfer that works from behind a home router. A rendezvous server introduces the two clients and the file rides mutually authenticated TLS 1.3 from your machine to theirs. No upload host, no copy left on somebody else's disk. NO CLEARTEXT.

Peers are pinned the first time you transfer with them. If that identity ever changes, the transfer stops and asks instead of quietly carrying on.

/seraphtransfer <nick>

Direct, encrypted, no logs

Jul 28, 2026, version 5.0.15

An encrypted conversation over that same direct link, in a floating window that never becomes a buffer. Nothing is logged, stored, or restored, and the invitation itself never lands in a query window.

Close the window and the conversation is gone from both machines. There is no history to hand over later, because there was never any history.

/seraphchat <nick>
