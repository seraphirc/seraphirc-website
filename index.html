SeraphIRC

IRC Modernized

SeraphIRC is a modern IRC client that runs on desktop, iPhone, and iPad. It supports IRCv3 and connects through Soju, ZNC, or directly to an IRC network.

Giphy 5.0.23-alpha · Aug 2, 2026 New

Some things are better said in motion

GIPHY has arrived. A GIF picker now sits in the composer next to the emoji button, or use /giphy to search via command. Find the one that says it better than you were going to, and send it.

Off until you bring your own Giphy API key. SeraphIRC ships no key and runs no proxy, so your searches go to Giphy under your agreement and SeraphIRC never sees them. The key lives in your operating system's keyring, never in a config file.

Settings > Integrations

Modern Mode 5.0.19-alpha · Jul 31, 2026

A fresh take on conversation

If Discord-style layouts are your thing, Modern Mode is familiar ground. SeraphIRC brings that grouped, avatar-led conversational flow to IRC. A refreshing change of pace from the classic transcript.

Avatars ride IRCv3 metadata and are opt-in, because fetching someone's picture tells their server your IP address. Anyone without one gets an identicon drawn on your own machine from their nick or account. Nothing is asked of a third party to build it.

Settings > Preferences > Appearance

Send Guard 5.0.18-alpha · Jul 30, 2026

Check yourself, before you... yeah.

IRC has no undo. Send Guard reads a message on its way to the wire and holds the ones that look like an accident: a password typed into a channel instead of a services window, a private line addressed to someone who isn't in the room, a forty-line paste into a busy channel.

A held message waits in a banner above the composer that names the destination and says which rule stopped it. Enter is deliberately not the confirm key, because the reflex that just sent the secret is a second tap on Enter. Send anyway is Ctrl+Enter, or Cmd+Enter on macOS, or a click. Escape drops the line, and editing it runs the check again.

Settings > Send Guard

Seraph Transfer 5.0.15-alpha · Jul 28, 2026

Innovating file transfers on IRC

Peer-to-peer file transfer that works from behind a home router. A rendezvous server introduces the two clients and the file rides mutually authenticated TLS 1.3 from your machine to theirs. No upload host, no copy left on somebody else's disk. NO CLEARTEXT.

Peers are pinned the first time you transfer with them. If that identity ever changes, the transfer stops and asks instead of quietly carrying on.

/seraphtransfer <nick>

Seraph Chat 5.0.15-alpha · Jul 28, 2026

Direct, encrypted, no logs

An encrypted conversation over that same direct link, in a floating window that never becomes a buffer. Nothing is logged, stored, or restored, and the invitation itself never lands in a query window.

Close the window and the conversation is gone from both machines. There is no history to hand over later, because there was never any history.

/seraphchat <nick>

Features

  • Multi-network IRC: keep direct networks, bouncer imports, channels, server buffers, and private messages organized in one workspace.
  • First class Soju support: import networks from a Soju bouncer, discover bouncer networks automatically, and manage them without leaving the client.
  • ZNC and direct IRC: connect through an existing ZNC setup, or talk directly to traditional networks when you don't run a bouncer at all.
  • IRCv3 negotiation: advertised capabilities such as SASL, server-time, account tags, away-notify, echo-message, batch, and chat history.
  • Identity confidence probing: the query window indicates whether a user is authenticated via SASL and on which account. A green check means verified. An orange question mark means unauthenticated or unknown.
  • Themeable interface: a prebuilt collection of common, beloved themes ready to use.
  • Dial in your atmosphere: use the Atmosphere slider to control how much cloud and starlight appears throughout the desktop client.
  • Diagnostics built in: inspect connection behavior, server responses, and client state without guessing what happened.
  • Nothing phones home: no analytics, no account requirement, no cloud dependency. The client talks to your networks and nothing else.
  • Desktop and mobile: take the desktop's familiar interface layout and flows with you on the go with your mobile device.
  • Mobile push notifications: receive push notifications on your mobile device when the setting is enabled on your app.
  • File uploads and DCC send/receive: use your Soju bouncer to upload files and share with others, or transfer files directly with DCC send and receive. Supports drag and drop with coordinates (including non-focused windows) and copy/paste.
  • Encrypted peer-to-peer transfers: Seraph Transfer sends a file straight to another user over mutually authenticated TLS 1.3, with no upload host and no copy left behind, even when you are both behind NAT.
  • Encrypted peer-to-peer chats: Seraph Chat opens a direct, mutually authenticated TLS 1.3 conversation with another user, even when you are both behind NAT.
  • Markdown and color formatting: write bold, italics, code spans, and colors with markdown or token syntax, all sent as standard IRC control codes that other clients understand. Spoilers are the exception, going out as literal ||text|| that SeraphIRC renders click-to-reveal.
  • Emoji support: display emojis and use the emoji picker to spruce up your chat.
  • Voice dictation: use your mobile device's microphone to translate your voice to IRC message. Handy for responding on the go.

Connect your way

If you keep IRC running through a bouncer, SeraphIRC understands that setup natively. If you don't, direct connections behave like any classic client.

  • Soju: import networks from Soju and manage bouncer-aware connections inside the client, including push notifications over soju.im/webpush.
  • ZNC: existing setups keep working, including command forwarding and the usual user/network style of login.
  • Direct networks: no bouncer? Connect straight to a network and everything works the way you expect.

Formatting

Two input syntaxes compile to standard IRC control codes, so other clients see ordinary formatting. Markdown is inline only, matching IRC formatting rather than CommonMark. Tokens are a superset that adds what markdown cannot express.

Markup

EffectMarkdownToken
Italic_italic_$i … $i
Bold__bold__$b … $b
Bold italic___both___$b$i … $i$b
Underlinen/a$u … $u
Strikethrough~~strike~~$s … $s
Monospace`code`$m … $m
Foreground colorn/a$c<n> … $c
Foreground + backgroundn/a$c<n>,<m> … $c
Spoiler||spoiler||n/a

Tokens are toggles, like the wire bytes they compile to, so overlapping ranges are legal: $ba $ib $bc $i renders bold "a ", bold italic "b", italic "c".

Numbers follow modern.ircdocs.horse: 16–98 use the fixed extended palette, 99 is the default color. Aliases and numbers are interchangeable, so $cred,lightgreen and $c04,09 send the same bytes. Themes may override individual entries for contrast, so the two columns are defaults, not fixed values.

  • Emphasis is underscores: _ follows CommonMark-style flanking, so snake_case and http://example.com/a_b_c stay literal. Asterisks are never markers.
  • Code spans win: formatting inside `…` is suppressed, and unterminated markers stay literal text.
  • Escapes: \ before a formatting character makes it literal. A backslash before anything else is itself literal, so C:\path needs no doubling.
  • Spoilers: the literal ||text|| goes on the wire and SeraphIRC renders it click-to-reveal. Other clients see readable pipes.
  • Per-message control: /format (/f) formats one message, /plain sends one raw, with -me, -msg, and -notice variants.
  • Automatic: Settings → Preferences → Chat sets auto_format to off, markdown, or markdown plus tokens as you type.
  • On the wire: bold 0x02, italic 0x1D, underline 0x1F, strikethrough 0x1E, monospace 0x11, color 0x03. Every attribute closes with its own toggle instead of a trailing reset, so a truncated line can't leak formatting.
