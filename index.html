SeraphIRC

Classic feel, modern capability

SeraphIRC is an easy-to-use IRC client for Linux, Windows, and iOS/macOS supporting direct connections, Soju, or ZNC bouncers.

Custom Themes 5.0.28 · Aug 4, 2026

Seraph your way

SeraphIRC ships with 21 themes, and until today that was the whole menu. Now any of them is a starting point. Clone one, give it a name, and recolor it from a floating editor that paints every change onto the running app as you make it. Every color is named for the thing it paints on screen, so you are choosing "Timestamps" or "Selected channel background", not deciphering a stylesheet. Pick from the palette the theme already uses, dial in something new on a full color wheel, or build a gradient. Your client, your colors.

Made something worth showing off? Export it. A theme travels as a small file that carries its name and colors and nothing else, never your networks or credentials, so you can hand it to a friend or drop it in a channel. Imported themes are checked before a single color lands. And the originals are never touched, so there is always a way back.

Multiline & Replies 5.0.24 · Aug 2, 2026

Additional IRCv3 Capabilities

Two IRCv3 extensions land together. Multiline lets a long message, or one with line breaks in it, travel as a single message instead of being chopped into a run of separate lines. Replies point a message at the one it answers, so the client draws that parent above it with a jump back to where it sits in the conversation.

Both fail gracefully, because most of IRC has not caught up yet. Multiline is used only where the network offers it and your message actually needs it. A reply that cannot be tagged opens with nick: instead, the way IRC has addressed people for thirty years, so it reads correctly on every client ever written. Where the tag does travel, SeraphIRC hides the now-redundant prefix and draws the preview in its place.

Right-click a message > Reply

Some things are better said in motion

GIPHY has arrived. A GIF picker now sits in the composer next to the emoji button, or use /giphy to search via command. Find the one that says it better than you were going to, and send it.

Modern Mode 5.0.19 · Jul 31, 2026

A fresh take on conversation

If Discord-style layouts are your thing, Modern Mode is familiar ground. SeraphIRC brings that grouped, avatar-led conversational flow to IRC. A refreshing change of pace from the classic transcript.

Avatars ride IRCv3 metadata and are opt-in, because fetching someone's picture tells their server your IP address. Anyone without one gets an identicon drawn on your own machine from their nick or account. Nothing is asked of a third party to build it.

Send Guard 5.0.18 · Jul 30, 2026

Check yourself, before you... yeah.

IRC has no undo. Send Guard reads a message on its way to the wire and holds the ones that look like an accident: a password typed into a channel instead of a services window, a private line addressed to someone who isn't in the room, a forty-line paste into a busy channel.

A held message waits in a banner above the composer that names the destination and says which rule stopped it. Enter is deliberately not the confirm key, because the reflex that just sent the secret is a second tap on Enter. Send anyway is Ctrl+Enter, or Cmd+Enter on macOS, or a click. Escape drops the line, and editing it runs the check again.

Seraph Transfer 5.0.15 · Jul 28, 2026

Innovating file transfers on IRC

Peer-to-peer file transfer that works from behind a home router. A rendezvous server introduces the two clients and the file rides mutually authenticated TLS 1.3 from your machine to theirs. No upload host, no copy left on somebody else's disk. NO CLEARTEXT.

Peers are pinned the first time you transfer with them. If that identity ever changes, the transfer stops and asks instead of quietly carrying on.

/seraphtransfer <nick>

Seraph Chat 5.0.15 · Jul 28, 2026

Direct, encrypted, no logs

An encrypted conversation over that same direct link, in a floating window that never becomes a buffer. Nothing is logged, stored, or restored, and the invitation itself never lands in a query window.

Close the window and the conversation is gone from both machines. There is no history to hand over later, because there was never any history.

/seraphchat <nick>

"Partial" means the capability is negotiated but not every code path uses it yet. Where a server advertises the ratified name instead of a draft one, the unprefixed variant (chathistory, read-marker, no-implicit-names) is negotiated too.

+draft/reply is a client-only tag rather than a capability. It rides on message-tags and goes out under both spellings, and SeraphIRC offers Reply as a threaded reply only where CLIENTTAGDENY says the server will pass it along. Everywhere else the same action addresses the nick instead.

Formatting

Two input syntaxes compile to standard IRC control codes, so other clients see ordinary formatting. Markdown is inline only, matching IRC formatting rather than CommonMark. Tokens are a superset that adds what markdown cannot express.

Markup

EffectMarkdownToken
Italic_italic_$i … $i
Bold__bold__$b … $b
Bold italic___both___$b$i … $i$b
Underlinen/a$u … $u
Strikethrough~~strike~~$s … $s
Monospace`code`$m … $m
Foreground colorn/a$c<n> … $c
Foreground + backgroundn/a$c<n>,<m> … $c
Spoiler||spoiler||n/a

Tokens are toggles, like the wire bytes they compile to, so overlapping ranges are legal: $ba $ib $bc $i renders bold "a ", bold italic "b", italic "c".

Numbers follow modern.ircdocs.horse: 16–98 use the fixed extended palette, 99 is the default color. Aliases and numbers are interchangeable, so $cred,lightgreen and $c04,09 send the same bytes. Themes may override individual entries for contrast, so the two columns are defaults, not fixed values.

Emphasis is underscores
_ follows CommonMark-style flanking, so snake_case and http://example.com/a_b_c stay literal. Asterisks are never markers.
Code spans win
Formatting inside `…` is suppressed, and unterminated markers stay literal text.
Escapes
\ before a formatting character makes it literal. A backslash before anything else is itself literal, so C:\path needs no doubling.
Spoilers
The literal ||text|| goes on the wire and SeraphIRC renders it click-to-reveal. Other clients see readable pipes.
Per-message control
/format (/f) formats one message, /plain sends one raw, with -me, -msg, and -notice variants.
Automatic
Settings → Preferences → Chat sets auto_format to off, markdown, or markdown plus tokens as you type.
On the wire
Bold 0x02, italic 0x1D, underline 0x1F, strikethrough 0x1E, monospace 0x11, color 0x03. Every attribute closes with its own toggle instead of a trailing reset, so a truncated line can't leak formatting.
